Say your last message again, in plain language, like one person talking to another.

- Rewrite what you already said. No tools, no new work, no answering a different question.
- Keep the answer. If the point was "the cache never invalidates, so drop the index", that must survive the rewrite. A version that reads well and loses the conclusion is a failure.
- Keep the concrete anchors: numbers, file paths, command names, the thing I have to act on.
- Cut jargon, hedging, and internal vocabulary. If a term has no plain replacement, keep it and define it in one clause.
- Short sentences, active voice. No list unless the original really was a list of steps.
- As short as the content allows. No lead-in like "in other words" or "to put it simply" — just say it.
